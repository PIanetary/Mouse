# Mouse
This is my mouse design for the bambu diy mouse kit.
I made it because it is cool to make and design your own mouse, and you can customize it later to look cool as well. It would be cool to design an entire working setup with a keyboard and mouse and be able to customize it with different colors depending on what you're feeling.
